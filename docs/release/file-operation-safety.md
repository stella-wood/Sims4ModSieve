# 文件操作的扫描快照核对

重复检测的扫描快照包含文件长度、UTC 修改时间、Windows 卷序列号与文件 ID，以及整个文件的 SHA-256。删除候选继承所在重复组的哈希。确认前的预检只核对文件戳与身份，不读取完整内容；执行删除时，每个候选流式计算当前 SHA-256，之后再核对文件戳与身份。批量交给回收站适配器前，所有通过的候选再次核对文件戳与身份。某个候选失败时，仅拒绝该文件并报告，其他通过的文件仍可操作。

冲突结果行的禁用和删除携带原扫描文件戳与身份；重复文件卡片的删除还携带重复组哈希。手动添加的禁用文件在禁用时采集身份；禁用记录保存该身份，改名后的 `.off` 文件在恢复或移入回收站前必须与记录匹配。旧禁用记录缺少身份时保留记录，拒绝自动恢复及删除，提示人工核对文件与记录。

处理旧禁用记录时，先关闭应用，备份 `disabled-mods.json` 和对应 `.off` 文件到工具管理目录之外；依据可信备份或用户自己的 Mod 来源核对内容，并检查原路径无同名文件。确认后从备份副本手动恢复所需文件，再清理已备份清单中的对应旧记录。工具不会用当前路径新采集的 ID 补写旧记录，因为无法证明它仍是当初被禁用的文件。

只读扫描在文件系统不提供稳定文件 ID 时仍可继续，文件动作则拒绝缺少身份的候选。重解析点不会参与文件身份核对与文件动作。身份读取或内容读取出错时，对对应文件保守失败。

Windows 回收站适配器和文件改名仍按路径执行；最后一次核对与系统实际动作之间存在竞态。当前核对缩短该窗口，但不能保证路径上的对象在此期间绝不被其他进程替换。

撤回和长期回收站恢复逐项执行；每个成功项立即从历史和最近一次撤回集合中移除并保存。后续项发生预期 IO 错误时只报告该项；已完成部分遇到取消时返回完成列表和剩余未恢复列表。开始前取消直接传播。
