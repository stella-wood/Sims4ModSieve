# Sims 4 Mod Sieve 0.1.0-alpha.1

适用于 Windows 10 / 11 x64。将 ZIP 完整解压到一个文件夹，再运行 `Sims4ModSieve.exe`；无需安装 .NET。保留同目录的其他文件。

## 使用

- 重复文件检测：添加要检查的目录，开始扫描，查看建议保留项，再勾选要删除的文件。确认后文件进入 Windows 回收站。
- 基础冲突排查：从「Mod 冲突检测 → 基础排查」开始。结果比较 package 资源和脚本模块；有差异不代表一定导致游戏报错，「未完成」也不代表没有冲突。
- 撤回与恢复：检测页撤回最近一次删除；「设置 → 删除与忽略 → 最近删除」可恢复更早的记录。原位置已有同名文件时不覆盖。
- 禁用与启用：禁用在原文件名后追加 `.off`，文件留在原目录；从已禁用列表或文件菜单启用。操作前关闭游戏。

文件在扫描后发生变化或被替换时，工具会拒绝对应操作，请重新扫描。旧禁用记录没有文件身份信息时不会自动恢复或删除；先备份清单与对应 `.off` 文件，再依据可信来源人工核对处理。

同一用户同时运行一个实例。正常关闭窗口会等待当前操作完成；强制结束进程或断电不属于正常关闭。

## 当前范围

提供完整文件重复检测及基础资源、脚本冲突排查。RefPack/QFS 内容、Zip64 脚本归档暂不支持；只识别受支持的 Python 字节码与模块内容，不执行脚本。报错日志分析、健康检查、二分排查、Tray 检测和一键体检尚未开放。

扫描在本机完成，不上传文件。导出报告可能包含完整本地路径，分享前检查。配置、管理清单和日志位于 `%LOCALAPPDATA%\Sims4ModSieve\`；删除解压目录不会删除这些数据。

更新时先关闭程序，再将新版本完整解压到新目录。自带运行时不会因系统安装了新版 .NET 而自动更新，请使用新的完整包。.NET 8 于 2026-11-10 结束支持，后续运行时支持计划仍待落实。
