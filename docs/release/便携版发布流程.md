# Windows x64 便携版

当前候选版本为 `0.1.0-alpha.1`。从仓库根目录运行 `eng/package-portable.ps1`，或从任意目录用该脚本的绝对路径调用。日常解决方案还原使用 `packages.lock.json`；脚本以显式 `RuntimeIdentifier=win-x64` 使用各产品项目的 `packages.win-x64.lock.json`，两种目标均以锁定模式还原。脚本随后查询 NuGet 直接与传递依赖漏洞，发布到 `artifacts/release/Sims4ModSieve-0.1.0-alpha.1-win-x64/`，并生成同名 ZIP 与 `.zip.sha256`。目录内的 `BUILD-INFO.txt` 记录源码提交、工作树是否有未提交修改及运行时版本；`SHA256SUMS.txt` 记录目录中每个文件的 SHA-256。只有构建、测试、漏洞门禁和包内容检查全部通过，才应把最终 ZIP 用于人工验收。

发布脚本需要 PowerShell 7，使用 `global.json` 固定的 .NET SDK 10.0.403 与 NuGet 锁文件。还原与发布均加载 Desktop 的 `Properties/PublishProfiles/PortableWinX64.pubxml`；profile 固定 `RuntimeFrameworkVersion=10.0.14`，随包包含 Microsoft.NETCore.App 和 Microsoft.WindowsDesktop.App 10.0.14，普通用户无需安装 .NET SDK 或 Desktop Runtime。[便携版使用说明](便携版使用说明.md) 随包复制为 `README.md`。自包含应用不会自动采用机器上新安装的运行时补丁。每次微软提供适用安全补丁时，应更新 profile 中的版本、运行时许可目录与相关验证，重新发布完整 ZIP。.NET 10 LTS 的支持期至 2028-11-14，维护日期以[微软支持策略](https://dotnet.microsoft.com/en-us/platform/support/policy/dotnet-core)为准。

## 文件布局

`PortableWinX64` 仅在显式选择该 profile 时生效，普通 build/test 不启用单文件发布或语言筛选。profile 开启 `PublishSingleFile`，只保留 `zh-Hans;en` 卫星资源；当前项目没有独立的本地化资源文件，界面文字写在 XAML/C# 中。托管程序集、保留的卫星资源、`.deps.json` 与 `.runtimeconfig.json` 都进入 EXE。发布还原新增的 `Microsoft.NET.ILLink.Tasks` 只用于 SDK 兼容性分析，不分发给用户。

`IncludeNativeLibrariesForSelfExtract`、`IncludeAllContentForSelfExtract`、`PublishTrimmed` 与 `EnableCompressionInSingleFile` 显式关闭。SDK 的 Windows 单文件启动器静态包含 CoreCLR/JIT；WPF 原生库由 Windows 从 EXE 旁加载，启动不进行 bundle 文件解压。顶层保留以下 5 个原生 DLL：

| DLL | 用途 |
|---|---|
| `D3DCompiler_47_cor3.dll` | WPF 图形渲染所用的 Direct3D 着色器编译器 |
| `PenImc_cor3.dll` | WPF 手写笔、触控输入支持 |
| `PresentationNative_cor3.dll` | WPF 原生窗口与平台支持 |
| `vcruntime140_cor3.dll` | WPF 原生组件使用的 Visual C++ 运行库 |
| `wpfgfx_cor3.dll` | WPF 原生绘图与合成引擎 |

顶层其余内容为 `Sims4ModSieve.exe`、`Assets/`、`licenses/`、`README.md`、`LICENSE`、`THIRD-PARTY-NOTICES.md`、`BUILD-INFO.txt` 和 `SHA256SUMS.txt`。字体本体是 WPF 内嵌 Resource，`Assets/Fonts/` 保留字体许可证。设置和日志继续保存到 AppData；外置许可证通过 `AppContext.BaseDirectory` 读取，与启动时的工作目录无关。

`eng/verify-portable-bundle.ps1` 按固定 SDK 的 bundle 格式读取实际 EXE 的标记和清单，不加载 SDK 程序集，检查嵌入的关键程序集、运行时版本、语言、无压缩且无须解压的条目，并拒绝顶层托管 DLL、JSON、PDB 或额外目录。CI 在打包后运行 `eng/test-portable-bundle.ps1`，对临时副本验证这些拒绝规则，不改候选包。`BUILD-INFO.txt` 另记录布局和保留语言。PDB 保留在构建输出，CI 将三个项目的调试符号单独上传为 `win-x64-symbols` 工件。

解压 ZIP 后运行 `Sims4ModSieve.exe`。便携版没有安装器、签名或自动更新器；用户数据仍按程序现有配置路径保存，删除 ZIP 不等于删除这些数据。最终候选须在没有 SDK、没有 NuGet 缓存的干净 Windows 10/11 x64 普通用户环境验证首次及再次启动、离线扫描和文件操作。本仓库的本地试包只证明自包含文件结构及开发机启动条件，不能替代该验证。

## 依赖与许可证

`LlamaLogic.Packages` 从 3.8.2 升到 4.9.0，保留 `DataBasePackedFile.FromPathAsync`、资源键和索引元数据的当前调用契约。上游在 4.9.0 移除 `SixLabors.ImageSharp` 与 `BCnEncoder.Net.ImageSharp` 依赖，改由 `StbImageSharp`/`StbImageWriteSharp` 提供图像相关依赖。本项目仅调用只读索引入口；Packages 测试的 53 项通过，3 项真实语料测试仍按既有条件跳过。该结果不能代替受控真实 package 语料的逐项对照。

`THIRD-PARTY-NOTICES.md` 列出当前运行时包与许可证；`licenses/` 中随包带完整授权文本或上游公有领域声明，及 .NET 10.0.14 自包含运行时的许可证、第三方通知。版权、授权和 NOTICE 来自对应 NuGet 包或其 nuspec 源码提交；`StbImageWriteSharp` 的包未提供独立许可证文件，随包保留其上游 README 的 Public Domain 声明。发布脚本检查关键原生 DLL、EXE 内的托管程序集和外置许可文件实际存在。

CI 在锁定还原后运行 `eng/check-vulnerabilities.ps1`。查询使用 `--no-restore`，避免 .NET 10 的自动还原覆盖已经生成的 win-x64 资产文件。该脚本解析 NuGet JSON 的项目与漏洞条目，拒绝查询错误、报告问题及任何直接或传递漏洞；原始报告保存在 `artifacts/release/vulnerabilities.json`。CI 只上传候选 ZIP、哈希及漏洞报告供验收，不创建 Tag 或 GitHub Release。
