# Sims 4 Mod Sieve

适用于 Windows 10 / 11 x64，自带 .NET 运行环境。版本见「设置 → 关于」。

## 安装

运行 `Sims4ModSieve-<版本>-setup.exe`，按中文向导选择安装位置和快捷方式。默认安装到 `%LOCALAPPDATA%\Programs\Sims4ModSieve`，不需要管理员权限。不要安装到游戏用户目录或 Mods／Tray 中。

当前 `0.1.0-alpha.1` 便携版用户需要下载安装版一次；已有设置和管理记录会继续使用。安装后可以删除旧便携程序目录，保留本机数据。

## 使用

- 重复文件检测：添加来源、扫描、查看建议保留项，再勾选要删除的文件；确认后文件进入 Windows 回收站。
- 基础冲突排查：比较 package 资源和脚本模块；有差异不代表一定导致游戏报错，「未完成」也不代表没有冲突。
- 删除与恢复：检测页撤回最近一次删除；设置中的「最近删除」可恢复更早记录，原位置已有同名文件时不覆盖。
- 禁用与启用：文件留在原目录，禁用时追加 `.off`；从已禁用列表或文件菜单启用。操作前关闭游戏，操作后发生变化的文件需要重新检查。

扫描、分析和文件操作在本机完成，不上传 Mod。导出报告可能包含完整本地路径，分享前请检查。设置、忽略名单、管理记录和日志保存在 `%LOCALAPPDATA%\Sims4ModSieve\`。

## 更新

启动时后台检查一次新版本。首页右下角出现更新图标后，点击「下载更新」；下载和校验完成，再点「重启并更新」。工具会等当前操作完成后关闭，安装新版并重新打开，设置和记录保留。下载期间可以取消；失败后可重试。

正常更新使用这个入口。更新器无法工作时，从项目 Releases 下载完整安装包，正常关闭工具后手动覆盖安装。

## 卸载

先关闭游戏，建议在「设置 → 删除与忽略 → 已禁用」中恢复 Mod，然后正常关闭工具，从 Windows「设置 → 应用」卸载。确认窗可勾选是否删除工具的本机数据，默认不勾选。不要直接双击程序目录中的 `unins000.exe`。

还有禁用 Mod 时，卸载器会显示数量、所在文件夹和打开按钮，默认取消卸载。选择「仍然卸载」后，需要自己手动去掉对应文件的 `.off` 后缀恢复；即使勾选清理数据，也会保留禁用记录，重装后继续使用。无法读取禁用记录时停止卸载，不允许继续。卸载器不会自动改名或删除 Mod。

启用失败时保留禁用记录和对应 `.off` 文件，依据工具提示核对。不要批量去掉所有 `.off` 后缀，其中可能有玩家自己或其他工具禁用的文件。

卸载默认保留本机数据，重新安装后可以继续使用。明确勾选删除本机数据，会清除设置、忽略名单、工具删除记录和日志，但保留尚未恢复的禁用记录；Windows 回收站里的文件仍可从系统回收站恢复。你的 Mods、存档和游戏文件，以及自行放进安装目录的文件，都不随卸载删除。

## 当前功能

提供完整文件重复检测及基础资源、脚本冲突排查。RefPack/QFS 内容、Zip64 脚本归档暂不支持；不执行脚本。报错日志分析、完整健康检查、二分排查、Tray 检测和一键体检尚未开放。
