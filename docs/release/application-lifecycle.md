# 应用生命周期

桌面程序使用 `%LOCALAPPDATA%/Sims4ModSieve/application.lock` 的独占文件句柄限制同一用户数据目录同时只有一个实例。句柄从窗口创建前持有到进程退出；第二次启动若无法取得锁，就直接退出，不读取或写入配置。异常退出由操作系统释放句柄，锁文件本身可以保留。

用户在界面忙碌期间关闭主窗口，窗口等待现有 `MainWindowViewModel.IsBusy` 结束，然后自动关闭。文件删除、恢复与禁用操作的收尾因此可在正常关闭时完成；扫描也遵循相同规则。操作成功或异常解除忙碌状态后，窗口取消等待订阅并关闭。此规则不覆盖操作系统强制终止进程或断电。
