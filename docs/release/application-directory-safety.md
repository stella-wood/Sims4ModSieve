# 程序目录保护

程序目录以当前进程的 `AppContext.BaseDirectory` 为准。路径先转成规范化绝对路径，再按目录边界判断；例如 `Sieve-backup` 不属于 `Sieve`。

重复、Package 和 Script 扫描共用文件发现入口，跳过程序目录及其所有子目录。用户直接添加程序目录或其子目录作为来源时也跳过，并产生 `application-directory-skipped` 问题记录，不能把该范围显示为完整检查通过。

删除预检及提交前复核拒绝程序目录内的文件；撤回和历史恢复拒绝向程序目录恢复。禁用、启用及已禁用文件的回收站恢复同样核对路径。拒绝时保留文件和未完成恢复记录，并向本机 `application-error.log` 追加拒绝路径，查看或复制诊断时沿用路径脱敏。

程序位于已设置或自动发现的 Mods / Tray 中时，窗口顶部显示位置提醒；切换页面保留提醒，更改目录设置后重新判断。提醒不阻止查看其他目录，程序目录的保护始终有效。便携版无法限制玩家的解压位置，安装器的路径拦截留待安装包实现。
