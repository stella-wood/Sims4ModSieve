# 安装与更新方案

2026-11-10 确定，用于 [issue #32](https://github.com/stella-wood/Sims4ModSieve/issues/32) 的安装包与应用内更新器。实施分支为 `codex/issue-32-installer-updater`。

## 发布方式

- 当前 `0.1.0-alpha.1` 便携包保留为历史版本；下一版起只发布 Windows x64 安装包及其 SHA-256，不再发布新便携 ZIP，也不为便携版开发文件替换式更新器。这项决定替代 issue #32 原先继续发布便携版的要求。
- 当前便携版用户通过已有首页提示前往发布页，下载安装版一次。安装版沿用 `%LOCALAPPDATA%\Sims4ModSieve\` 的设置、忽略名单、禁用记录和删除历史。
- 安装版后续正常更新统一使用首页入口。GitHub Releases 提供下载来源，并保留首次安装、更新器故障时的手动安装入口。
- 本次接入安装与更新能力，不调整产品版本、不创建正式 Release。预发布或正式版本的发布由维护者决定；启动检查沿用当前的最新正式版本通道。

## 首次安装

使用 Inno Setup 生成 `Sims4ModSieve-<版本>-setup.exe`，版本从 [Directory.Build.props](../../Directory.Build.props) 所定义的项目最终版本读取，不另维护版本号。

中文向导默认按用户安装至 `%LOCALAPPDATA%\Programs\Sims4ModSieve`，不申请管理员权限。用户可以选择其他安装位置；开始菜单快捷方式默认勾选，桌面快捷方式可选，完成后可立即运行。安装版自带 .NET 运行环境。

固定 AppId，后续版本覆盖原安装；复用已验证的自包含发布布局与完整许可证。程序图标使用透明底紫色晶体，安装包使用白色圆角底加绿色下载标记，分别由 `eng/generate-brand-icon.ps1` 和它的 `-Installer` 参数生成多尺寸 ICO。构建工具固定版本，记录中文语言文件及 Inno Setup 的来源与许可。

选择位置和真正安装前都检查路径，拒绝安装到 `Electronic Arts\The Sims 4` 目录及其子目录、自动检测或用户配置的 Mods／Tray 目录及其子目录。路径按目录边界比较，处理大小写、规范化和目录链接，避免相似前缀误判或路径别名绕过。

## 首页更新

1. 启动时后台检查一次；发现新版本后显示现有首页更新入口。
2. 点击「下载更新」，在工具内下载对应安装包并显示进度，支持取消。下载不影响当前检测结果和文件操作。
3. 校验下载来源、目标版本、文件大小和 SHA-256；完整下载并通过校验后才允许执行。缺少安装包或校验信息时提示无法更新，不猜测下载地址或执行其他资产。
4. 下载完成后显示「重启并更新」。如果还有扫描、删除、恢复或禁用操作，等待现有操作结束，再正常关闭程序并交给安装包更新。
5. 安装包使用原安装路径和快捷方式选择，更新成功后重新打开工具；设置和记录沿用原数据目录，不修改 Mod。

下载失败、取消或校验失败不会替换当前程序；界面给出结果并允许重试。安装无法开始时保留当前进程并报告原因。安装执行失败时显示失败，不报告更新成功。用户关闭工具时取消仍在进行的下载。

手动安装、自动更新和卸载均与现有 [应用生命周期](application-lifecycle.md) 协调，在程序正常退出后才动程序文件；不强制结束正在操作文件的进程，并防止安装期间重新启动造成竞争。

## 卸载

安装包登记到 Windows「设置 → 应用」，卸载时删除所安装的程序文件、快捷方式和卸载登记，不递归清空用户选择的安装目录。

Windows「设置 → 应用」登记的卸载入口直接显示 Pascal Script 自建紧凑确认窗。确认窗与禁用警告窗的标题栏均显示程序图标及「卸载 Sims4ModSieve」。确认正文标题前显示警告图标，说明只删除程序文件，Mods、存档和游戏文件不会被删除。默认不勾选「同时删除本工具的设置、忽略名单、删除记录和日志」；底部左侧为「否」，右侧为默认的「是」，点击「是」或按回车继续，「否」和关闭窗口均保留程序与数据。确认与数据选择合并为一步，不再连续弹出默认确认和是／否数据询问。

卸载前只读检查工具的禁用记录。还有未恢复的 Mod 时，用紧凑窗口显示数量、当前所在文件夹列表和小字号、无边框底色的「打开文件夹」文字入口，说明以后需要自己手动去掉 `.off` 后缀恢复。文字入口放在列表下方，向内缩进，并与底部按钮分行留出间距。底部左侧为白底红字的「仍然卸载」按钮，右侧为默认的「取消卸载」，不再显示单独的危险操作注释。用户明确选择继续后，即使勾选删除本机数据，也原样保留 `disabled-mods.json`，以后重装继续使用。记录读取失败仍停止卸载，不提供继续操作。不自动改名或删除任何 Mod；复用现有记录与文件身份规则，不把身份不匹配或旧记录当作已处理。

本机数据默认保留；明确勾选后只清理 `%LOCALAPPDATA%\Sims4ModSieve\` 内的工具数据，保留上述未恢复禁用记录，不跟随目录链接。真正的静默卸载保留数据，有未处理禁用记录时停止。设置页的「卸载前清理」按钮仍属于 [issue #30](https://github.com/stella-wood/Sims4ModSieve/issues/30)，本次不扩展到该页面。

Inno 的原生确认发生在 `InitializeUninstall` 之后，因此登记入口使用 `/SILENT /SIEVEINTERACTIVE=1` 仅跳过原生确认，脚本仍显示交互窗口；`QuietUninstallString` 保留真正静默命令。直接不带参数运行 `unins000.exe` 会提示使用 Windows「设置 → 应用」，避免出现另一套确认流程。`[Messages]` 同时覆盖 `ConfirmUninstall`，不使用「完全移除及其所有组件」文案。

## 实施与验证

按顺序实现安装脚本及打包入口、只读安装检查与运行互斥、首页下载和更新交接、CI 候选产物与使用说明。沿用现有自包含发布与包检查能力，CI 不再上传新便携 ZIP。

编译要求零警告零错误；改动期间只运行相关测试。自动测试覆盖路径拦截、禁用清单异常、运行互斥、版本与下载资产匹配、取消、损坏下载、失败重试、忙碌时等待和更新按钮交互。

安装、覆盖升级、卸载与数据清理只在临时目录和临时用户数据中验证；实际打开中文向导和首页更新弹层检查显示与点击行为。干净 Windows 10／11 普通用户、没有开发工具环境的安装与启动单独记录验证结果；未验证的环境不报告通过。

实现与验证完成后创建关联 #32 的新 PR；不自动合并或发布。
