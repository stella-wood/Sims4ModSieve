# 0004 删除只进回收站；禁用用改名 `.off`，取代隔离区

状态：已采纳

## 决定

- 删除：移进 Windows 回收站，不直接删。程序记下回收站历史，可以撤回。
- 禁用：文件原地改名加 `.off`，游戏就不读它；恢复时去掉 `.off`。取代早期的「隔离区」（把文件挪到另一个文件夹）。

## 比过的方案

- 直接删除：误删无法恢复，对整理 Mod 的工具来说风险太大。
- 隔离区：文件挪走后玩家找不到原来在哪，跨盘挪动还慢；改名不挪位置，恢复只是再改一次名。

## 代价

`.off` 文件还留在 Mods 文件夹里占空间，玩家需要到「已禁用」里统一处理。规则见[设置页面方案](../design/设置页面方案-v1.md#已禁用)。
