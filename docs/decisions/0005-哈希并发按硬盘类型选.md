# 0005 查重复的并发按硬盘类型自动选

状态：已采纳
日期：2026-11-17（#48）

## 决定

算整文件哈希时：机械硬盘 1 路，确认全是固态 4 路，判断不出来 2 路。设置里可以手动选 1 / 2 / 4 / 8。

## 比过的方案

- 固定一个并发数：固态上并发高明显更快，机械硬盘上并发高反而因为磁头来回跳变慢。
- 按 CPU 核数：瓶颈在读盘不在算哈希，核数不说明问题。

## 代价

要判断硬盘类型（`WindowsStorageProfile`），判断失败时退回 2 路。HDD 上的实测验收还待补，见[实施计划](../architecture/性能优化与重构实施计划.md)。
