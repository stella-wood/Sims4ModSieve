# 0001 以后只发安装包，不再发便携 ZIP

状态：已采纳
日期：2026-11-10

## 背景

0.1.0-alpha.1 发的是便携 ZIP。要做应用内更新（issue #32），便携版没法可靠地替换自己正在运行的文件。

## 决定

从下一版起只发 Windows x64 安装包和它的 SHA-256。安装版首页能直接下载更新。0.1.0-alpha.1 便携包保留为历史版本。

## 比过的方案

- 两种都发：要维护两套打包、两套更新逻辑，测试翻倍。
- 只发便携版、更新时跳 GitHub 页面：玩家要自己下载解压覆盖，容易覆盖错位置。

## 代价

不想安装的玩家没有便携版可用。详见[安装与更新方案](../release/安装与更新方案.md)。
