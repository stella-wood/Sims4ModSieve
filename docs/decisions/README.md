# 决策记录

一个决定一份小文件，写清选了什么、比过什么、为什么。Agent 读得到旧决定，就不会把已经否掉的方案再推一遍。

**只在真有取舍时写**：难回滚的、脱离上下文看会觉得奇怪的、比过几个方案才定的。顺手的小改动不写，不然文档会通胀。

想推翻一条：新写一份，旧的那份状态改成「被 00xx 取代」，不删。

格式：

```markdown

## 背景
## 决定
## 比过的方案

```
