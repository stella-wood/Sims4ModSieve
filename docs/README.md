# 文档目录

第一次来先读这三份：

1. [架构概览 v4](architecture/架构概览-v4.md)：程序现在长什么样，每块代码在哪、数据怎么流。
2. [冲突评级与拆分标准](product/冲突评级与拆分标准.md)：结果怎么分红黄绿，界面和 CLI 共用。
3. 仓库根目录的 [AGENTS.md](../AGENTS.md)：给 Agent 的工作规矩和不能改的业务规则。

根目录还有：

- [CONTEXT.md](../CONTEXT.md)：词汇表，Sieve 的自造词各指什么、代码里叫什么。
- [CHANGELOG.md](../CHANGELOG.md)：每个版本改了什么。
- [DESIGN.md](../DESIGN.md)：设计令牌（颜色、字号、间距、圆角）和组件样式，写 XAML 只用这里的名字。
- [决策记录](decisions/README.md)：选了什么、比过什么、为什么。

每份文档标了类型：

- **现行**：描述现在的代码和规则，跟代码对不上时以代码为准，并修正文档。
- **计划**：还没做完的事，做完的部分会过时，开工前先核对现状。
- **记录**：某一次验收或调研当时的结果，不再更新。
