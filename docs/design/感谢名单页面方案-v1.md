# 感谢名单页面方案 v1

设置分类中「感谢名单」位于「关于」之后，前置空心爱心矢量图标。内容依次为标题、支持者名字、爱发电按钮和居中的礼花筒。名单区域用暖灰底色与留白分区，无边框。

## 名单维护

名字只维护在 [supporters.json](../../src/Sims4ModSieve.Desktop/Assets/supporters.json)，格式为 JSON 字符串数组，按文件顺序展示。增删名字后重新构建发版，不改代码。该文件作为嵌入资源进入程序集，不单独复制到构建或发布目录；运行时不读取外部同名文件，不联网获取名单。

空数组、空文件、`null`、读取或解析失败均隐藏名单区域，其他内容照常显示。空白名字和 `null` 项跳过，其余名字去掉首尾空白。

当前 demo 名单为 `[]`；爱发电链接待作者提供，按钮暂禁用。第 20 次彩蛋暂用以下文字，待作者确认：

> 感谢每一位提过建议、反馈过问题的人，
> 请我吃过薯片的朋友们，以及亲爱的 agent 们。
>
> 谢谢你还在使用它

## 点击效果

板块内左键点击从点击位置向右上方飘出爱心，逐渐淡出。450 毫秒内连续点击时，每次由 1 颗递增至最多 3 颗；暂停或离开后重置。按钮保持原本响应，覆盖层不参与命中。

礼花筒向上喷出彩带与花瓣，再落回板块内。两者共用粒子运动与生命周期；花瓣比例常量 `PetalRatio` 为 25%，彩带翻转、下落较快，花瓣横向飘动、下落较慢。图标从提供的 SVG 转成内嵌 WPF `Path`，来源见[第三方声明](../../THIRD-PARTY-NOTICES.md#感谢名单彩蛋图标)。

| 礼花筒点击次数 | 额外效果 |
|---|---|
| 5 | Clawd 小螃蟹 |
| 6 | 星星 |
| 7 | ChatGPT 图标，代表 Codex |
| 8 | DeepSeek 鲸鱼 |
| 20 | 感谢文字渐显，约 6 秒后消失 |

后续点击继续喷礼花，文字在离开分类前不再重复出现。切换设置分类、返回首页或卸载页面均停止动画、移除元素、清零点击计数；不会保存状态、写文件或操作 Mod。

所有效果裁剪到板块内。同屏最多 30 颗爱心、80 个礼花粒子（含彩蛋图标）；达到对应上限时跳过新粒子，已有粒子继续播放。动画结束即移除元素，没有动画时停止帧更新计时器。
