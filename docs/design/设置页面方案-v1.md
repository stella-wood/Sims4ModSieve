# 设置页面方案 v1

设置通过顶部导航进入，包含「文件夹」「诊断与反馈」「关于」。首次进入显示文件夹，同次运行保留最后分类，重启回到文件夹。四个主页面互斥；设置导航和路径修改使用现有 `IsBusy`，不重建检测会话。

## 页面布局

顶部导航保留原布局。左侧固定分类栏，右侧白底、独立滚动，内容居中且最大宽度 760 DIP。侧栏标题 19、分类标题 28；分类图标为矢量，实际控件承载完整矩形命中和键盘操作。

设置名称与说明在左，路径及操作在右。分组边框 `#F0EEEB`、圆角 3；操作按钮 `#F2F1EF`、圆角 4；「重新查找默认目录」使用品牌紫 `#6F5A91`。这些资源只定义在 `SettingsPage.Resources`，不改变其他页面样式。路径可截断，Tooltip 显示全文。

## 文件夹与保存

- 默认 Mods 为两种检测共用的 `ModsRoot`。设置页选择或采用候选后立即保存，成功后才发布新值；失败保留旧值并就地反馈。
- 设置页修改默认位置不改变任一页已有来源、勾选、结果、筛选、展开或撤回记录，不触发扫描。两页「添加」使用最新默认位置作为选择器初始目录。
- 检测页原有「更改」仍在保存成功后加入或启用当前页的新 Mods 来源，旧来源保留。
- `TrayRoot` 独立保存，初始未设置；可以选择、更改、打开或清除。清除只改配置。文案为「用于图库检测，当前尚未开放」，不接入扫描。
- 取消选择不改值；不可用的已保存路径保留并显示提示。打开失败给反馈，不创建游戏目录。
- 「重新查找默认目录」分别检查系统 `MyDocuments/Electronic Arts/The Sims 4/Mods` 或 `Tray`，兼容文档重定向。不遍历磁盘，不按自定义 Mods 位置猜测 Tray。找到后在当前行显示完整候选路径及「使用此目录／取消」，明确采用后才保存；未找到不清空旧值。

配置继续使用 `%LOCALAPPDATA%/Sims4ModSieve/duplicate-settings.json`，保存 `ModsRoot`、`TrayRoot` 和空 `Sources`。先写同目录临时文件，再替换当前文件，避免写入中途失败破坏已有 JSON。缺少 `TrayRoot` 的旧 JSON 可读取；当前配置不存在时依次读取 `Sim4ModSieve`、`Sims4ModDoctor` 旧目录，保存写入当前目录并保留旧文件。检测页保存 Mods 时也携带当前 Tray。

启动时，两页只以有效配置中的 Mods 初始化默认勾选范围，忽略历史来源；未设置 Mods 时沿用已有默认目录发现逻辑。来源及结果会话仍遵循 [Agent 指南](../../AGENTS.md#73-结果会话)。

## 诊断与反馈

错误记录读取本工具数据目录中的 `application-error.log`、`startup-error.log`，不读游戏日志。进入诊断分类或点击刷新时异步读取；文件缺失、空日志与单文件读取失败分别处理，一个文件失败不影响另一个。无错误显示「暂时没有错误记录」，有内容可键盘或鼠标展开。

每个日志最多读取前 65536 个字符，超出时在显示和复制文本中注明部分内容。显示与复制共用脱敏结果：Windows 用户目录中的用户名替换为 `<用户>`，同时处理普通路径和多重反斜杠转义路径；磁盘原日志不修改。

复制诊断信息包含程序集实际版本、系统版本及可读取的错误日志，无日志仍可复制基本信息。剪贴板、日志目录或浏览器打开失败均就地反馈，不调用扫描错误处理，不改变忙碌状态。GitHub 反馈链接仅在用户点击时交给系统浏览器。

「最近一次扫描计时」独立显示最后结束的扫描，不计入错误记录。标题在框外；框沿用内容区最大宽度 760 DIP，有计时记录时高度 280 DIP，无记录或日志为空时显示「尚无扫描计时」并随一行内容收起，不预留结果区高度。正文 12 DIP，使用只读技术纯文本，细滚动条只作用于该框。文本分扫描摘要、按执行顺序编号的阶段计时、机器与统计口径；相邻编号阶段不插空行，数值使用千位分隔、s/ms 与 KiB/MiB/GiB。每阶段写明耗时、占比、并发上限和文件/资源规模，内容读取阶段补充解压与未完成计数。右上角复制矢量图标固定在框内，图形 16×16 DIP、矩形热区 24×24 DIP；无下方复制按钮。复制包含整个框内文本，滚动位置不影响复制范围。已有日志可直接整理显示，磁盘日志格式保持原样。计时默认启用，日志位置、阶段及计数口径见 [扫描性能计时](../architecture/扫描性能计时.md)。
