# 设置页面方案 v1

设置通过顶部导航进入，包含「常规」「删除与忽略」「诊断与反馈」「关于」。「常规」使用六齿齿轮矢量图标，页面标题同名。首次进入显示常规，同次运行保留最后分类，重启回到常规。四个主页面互斥；设置导航和路径修改使用现有 `IsBusy`，不重建检测会话。

## 页面布局

顶部导航保留原布局。左侧固定分类栏，右侧白底、独立滚动。所有分类共用内容区布局，边距与宽度规则遵循 [UI 设计风格规范 · 设置页](UI设计风格规范-v1.md#34-设置页)。侧栏标题 19、分类标题 28；分类图标为矢量，实际控件承载完整矩形命中和键盘操作。

设置页外层及计时、错误记录、许可正文的内层纵向滚动条共用 [UI 设计风格规范 · 工作页](UI设计风格规范-v1.md#33-工作页) 的外观与显隐规则。内层滚动只移动当前文本框，不触发外层滚动条显隐。

设置名称与说明在左，路径及操作在右。分组边框 `#F0EEEB`、圆角 3；操作按钮 `#F2F1EF`、圆角 4；「重新查找默认目录」使用品牌紫 `#6F5A91`。这些资源只定义在 `SettingsPage.Resources`，不改变其他页面样式。路径可截断，Tooltip 显示全文。

设置页操作按钮和左侧分类导航获得焦点后不显示边框或系统虚线焦点框，保留键盘导航及激活操作。

设置页文字按钮使用手形光标，悬停时仅文字使用 [UI 设计风格规范](UI设计风格规范-v1.md#4-颜色规范) 的文字悬停强调色，不显示悬停底色。

## 文件夹与保存

- 默认 Mods 为两种检测共用的 `ModsRoot`。设置页选择或采用候选后立即保存，成功后才发布新值；失败保留旧值并就地反馈。
- 设置页修改默认位置不改变任一页已有来源、勾选、结果、筛选、展开或撤回记录，不触发扫描。两页「添加」使用最新默认位置作为选择器初始目录。
- 检测页原有「更改」仍在保存成功后加入或启用当前页的新 Mods 来源，旧来源保留。
- `TrayRoot` 独立保存，初始未设置；可以选择、更改或打开。文案为「用于图库检测，当前尚未开放」，不接入扫描。
- 取消选择不改值；不可用的已保存路径保留并显示提示。打开失败给反馈，不创建游戏目录。
- 「重新查找默认目录」分别检查系统 `MyDocuments/Electronic Arts/The Sims 4/Mods` 或 `Tray`，兼容文档重定向。不遍历磁盘，不按自定义 Mods 位置猜测 Tray。找到后在当前行显示完整候选路径及「使用此目录／取消」，明确采用后才保存；未找到不清空旧值。

配置继续使用 `%LOCALAPPDATA%/Sims4ModSieve/duplicate-settings.json`，保存 `ModsRoot`、`TrayRoot` 和空 `Sources`。先写同目录临时文件，再替换当前文件，避免写入中途失败破坏已有 JSON。缺少 `TrayRoot` 的旧 JSON 可读取；当前配置不存在时依次读取 `Sim4ModSieve`、`Sims4ModDoctor` 旧目录，保存写入当前目录并保留旧文件。检测页保存 Mods 时也携带当前 Tray。

启动时，两页只以有效配置中的 Mods 初始化默认勾选范围，忽略历史来源；未设置 Mods 时沿用已有默认目录发现逻辑。来源及结果会话仍遵循 [Agent 指南](../../AGENTS.md#73-结果会话)。

## 删除与忽略

分类图标为文件夹矢量，依次展示已禁用、最近删除、已忽略。进入分类或从其他页面返回时自动刷新。页面大标题「删除与忽略」右侧提供唯一的文字「刷新」，统一重新读取三个列表；各列表不另设刷新入口。已忽略提供「＋添加」；已禁用的操作见[下文](#已禁用)。三个列表有文件时显示「多选」，空列表隐藏「多选」及表头，显示短空状态，不显示记录总计。

默认无复选框；进入多选后，顶部从左到右显示「全选」「清空勾选」「取消多选」，隐藏该列表的「＋添加」，列表内显示复选框。底部显示已选计数及各自的批量操作，未勾选时操作不可用；「启用所选」「恢复所选」使用浅紫底、深紫字，「删除」和「取消忽略」保留普通按钮配色。退出多选清空选择并恢复添加入口，最后一项移除后自动退出多选。各列表的选择互不影响；最近删除仍无添加入口，刷新和文件夹入口不受多选影响。

三个列表共用列宽：文件、大小、禁用时间／删除时间／忽略时间、操作。文件名和完整原路径在左，大小与时间居中，操作靠最右；路径截断且 Tooltip 保留全文，时间单行，列宽不足时截断并用 Tooltip 提供完整时间。文件名、路径、大小、时间、操作和表头均为 12 DIP。文件行上下内边距各 4 DIP，最小行高 50 DIP；行间没有横线，只保留 `#E8E8E8` 的 1 DIP 外框和 `#F0F0F0` 表头线，背景白色。三个表头固定，各自的文件列表最多 150 DIP 高、内部虚拟化滚动，滚轮到边界不带动整页。已禁用与最近删除间隔 36 DIP，最近删除与已忽略间隔 80 DIP。

最近删除只记录本工具通过两种检测页、已禁用或已忽略列表成功移入 Windows 回收站的条目，保留原路径、大小、删除时间、文件戳和该次具体回收站条目身份，跨批次及重启保存。刷新时核对精确条目，确认已不存在的静默移除；读取或访问失败保留并提示，不把失败当永久删除。行和批量操作仍称「恢复」「恢复所选」。恢复时才发现条目丢失，先显示找不到文件的错误，确认后刷新移除。恢复成功立即离开列表，原位置有同名文件时不覆盖；部分成功和失败分别处理。

长期删除记录与「撤回最近一次批量删除」分开；新扫描或清空来源只清除会话撤回，不清空历史。从设置恢复最新批次的一部分后，撤回仅处理该批次尚未恢复的条目。同路径不同次删除使用独立身份，不能凭原路径清除其他版本的记录。恢复只回填仍属于当前扫描代次、文件戳匹配的原成员，不将旧历史组放入新扫描。

文件忽略按规范化完整路径、Windows 大小写不敏感语义长期保存，不按内容哈希判断。名单不因重启、新扫描、清空来源或文件暂时不存在而清除；相同路径替换文件仍受该路径规则控制。只控制冲突页各原组的文件显示，包括该页重复文件卡与独立未完成文件；独立重复检测页不受影响。原分组、组号、成员关系和扫描事实保留，不排除扫描输入，不重新分组或判断组成立。默认隐藏已忽略文件；「显示已忽略」后在原组显示并标记，取消忽略恢复普通显示。折叠的重复副本中有被忽略路径时，显示已忽略会展开这些具体文件，避免标记被代表文件吞掉。整组忽略继续仅为当前结果会话状态。

已忽略的「＋添加」打开原生多文件选择器，默认列出 `.package` 与 `.ts4script`，可切换所有文件；取消选择不变更名单。按完整路径去重，单项或批量取消忽略只删除名单规则，不移动或删除文件。保存成功后才发布新名单，失败保留原状态。

已忽略列表每行及多选底部从左到右提供「取消忽略」「删除」。「删除」只处理对应或当前勾选的实际文件，沿用[删除确认](../../AGENTS.md#72-删除与撤回)，一次确认并复核文件大小和修改时间后移入 Windows 回收站；部分成功与失败分别报告，成功项记入最近删除并组成最近一次可撤回批次。删除与取消忽略独立：删除文件保留长期路径规则，文件不存在也不移除名单；从最近删除恢复或撤回后，该路径仍受忽略规则控制。删除成功项清空勾选，失败项保留勾选，便于重试。删除成功同步两种检测的当前结果；恢复只回填当前扫描代次且文件戳匹配的原成员。

删除记录和忽略名单保存于 `%LOCALAPPDATA%/Sims4ModSieve/file-management.json`，与 Mods／Tray 配置分离；同目录临时文件写完再替换，避免保存一个设置覆盖其他设置。删除成功后若记录保存失败，保留本次进程中的记录并报告保存失败，后续刷新重试保存。旧配置中的 `QuarantineRoot` 不再使用，读取时保留原有删除记录和忽略名单；不删除旧路径下的文件。

### 已禁用

已禁用替代隔离区，不再提供目录选择或搬移功能。「＋添加」打开原生多文件选择器，只接受 `.package` 与 `.ts4script`；按 Windows 完整路径大小写不敏感语义去重。禁用在原文件名后追加 `.off`，例如 `a.package` 变为 `a.package.off`，文件仍在原目录；启用去掉本工具追加的后缀。禁用和启用前提醒玩家先关闭游戏，取消选择或确认均不改文件；启用的确认与成功提示均使用「启用」措辞。成功后提示可以删除 `localthumbcache.package`，工具不自动清理缓存。

清单为 `%LOCALAPPDATA%/Sims4ModSieve/disabled-mods.json`，独立记录条目身份、原路径、大小、修改时间和禁用时间，跨重启保留。只管理本工具记录的文件，不遍历或接管其他 `.off` 文件。列表显示原文件名、完整原路径和禁用时间。提供「＋添加」及每行「启用」「删除」；多选底部从左到右提供「启用所选」「删除」。全部启用通过「全选」后执行「启用所选」，不另设「启用全部」入口。刷新结合清单与磁盘状态，不因新扫描或来源清空丢失禁用记录。

每项禁用先用同目录临时文件原子保存记录，再改名；清单保存失败则不改文件。改名失败后尝试移除该项预记账，清理失败保留记录并报告。启用先改回原名，再移除记录；若清单保存失败，分别报告文件已启用与清单未保存。下次读取时，未处于回收流程且仅原文件存在、文件戳匹配的记录会被清理，用于收尾未完成的禁用或启用。普通禁用记录的两种路径都不存在时保留记录并报告；`.off` 文件戳变化时保留记录并拒绝启用。禁用路径始终由清单原路径追加 `.off` 推导，不接受清单指定任意目标路径。

禁用目标或启用原路径已有同名文件时跳过该项，不覆盖；部分成功和失败分别报告。原地禁用和启用不占用删除撤回记录。成功项同步到两种检测的当前结果：重复检测仍移除禁用成员；冲突检测保留当前扫描的原文件行和关系，标记「已禁用」，路径显示实际 `.off` 路径，右键菜单可启用。行内关系仅表示扫描时的事实。启用只回填仍属于当前扫描代次且文件戳匹配的原成员，不把旧扫描结果带入新扫描。

行与批量「删除」沿用[删除确认](../../AGENTS.md#72-删除与撤回)，只把对应或勾选的实际 `.off` 文件移入 Windows 回收站，不改动原名同名文件。批量操作只确认一次，成功项组成最近一次删除批次；部分成功与失败分别报告，成功项离开已禁用列表并进入最近删除，取消或失败项保留禁用信息。删除记录保留禁用来源，从最近删除恢复或撤回该批次时，只恢复 `.off` 文件并重新纳入已禁用管理，不直接启用；重复检测不回填，冲突检测只恢复当前扫描中仍匹配文件戳的历史行并标记「已禁用」。启用仍通过已禁用列表或文件行右键菜单执行。

删除前先在禁用清单保存回收意图；取得具体回收站条目身份后，先保存到禁用清单的回收镜像，再保存长期删除记录。长期删除记录单独保存失败时，重启可用已落盘的镜像补回精确记录；只有预记账而未保存回收身份时，不推测回收站条目。回收站恢复前预记账，确认 `.off` 已实际恢复且文件戳匹配后重新激活禁用记录，重启也按此收尾待恢复记录；未发起恢复的回收记录不会因同名 `.off` 出现而重新激活。

二分排查和自动 Mod 分组尚未接入。`.off` 在真实游戏及自定义 `Resource.cfg` 下的加载行为尚未实测。

## 诊断与反馈

错误记录读取本工具数据目录中的 `application-error.log`、`startup-error.log`，不读游戏日志。进入诊断分类或点击刷新时异步读取；文件缺失、空日志与单文件读取失败分别处理，一个文件失败不影响另一个。区域复用扫描计时的文本框、复制图标与细滚动条样式，标题在框外；有记录或读取失败时框高 280 DIP，框内为 12 DIP 只读纯文本，包含产品版本、系统版本及按文件区分的运行／启动错误。无错误时只显示「暂时没有错误记录」并随一行内容收起。框内右上角复制图标固定，不随文本滚动。

扫描计时和错误记录各自在标题旁放打开文件夹矢量图标，图形 16×16 DIP、矩形热区 24×24 DIP，打开同一工具日志目录；标题行与下方框体间距为 12 DIP。标题行最右侧各放「刷新」，使用微软雅黑 UI，字号 14 DIP，默认灰色，悬停仅文字使用 [UI 设计风格规范](UI设计风格规范-v1.md#4-颜色规范) 的文字悬停强调色，不显示底色、边框或按下效果。两处刷新共用现有诊断刷新命令，同时重新读取计时和错误日志。框下不再放打开文件夹或刷新按钮。

每个日志最多读取前 65536 个字符，超出时在显示和复制文本中注明部分内容。显示与复制共用脱敏结果：Windows 用户目录中的用户名替换为 `<用户>`，同时处理普通路径和多重反斜杠转义路径；磁盘原日志不修改。

复制诊断信息包含整个框内的诊断内容，无日志仍可复制程序集实际版本、系统版本和日志缺失或为空的状态。剪贴板、日志目录或浏览器打开失败均就地反馈，不调用扫描错误处理，不改变忙碌状态。GitHub 反馈链接仅在用户点击时交给系统浏览器。

「最近一次扫描计时」独立显示最后结束的扫描，不计入错误记录。标题在框外；框随诊断内容区宽度伸展，有计时记录时高度 280 DIP，无记录或日志为空时显示「尚无扫描计时」并随一行内容收起，不预留结果区高度。正文 12 DIP，使用只读技术纯文本，细滚动条只作用于该框。文本分扫描摘要、按执行顺序编号的阶段计时、机器与统计口径；相邻编号阶段不插空行，数值使用千位分隔、s/ms 与 KiB/MiB/GiB。每阶段写明耗时、占比、并发上限和文件/资源规模，内容读取阶段补充解压与未完成计数。右上角复制矢量图标固定在框内，图形 16×16 DIP、矩形热区 24×24 DIP；无下方复制按钮。复制包含整个框内文本，滚动位置不影响复制范围。已有日志可直接整理显示，磁盘日志格式保持原样。计时默认启用，日志位置、阶段及计数口径见 [扫描性能计时](../architecture/扫描性能计时.md)。
